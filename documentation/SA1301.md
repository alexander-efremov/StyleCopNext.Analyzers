## Cause

There are currently no situations in which this rule will fire.

## Rule description

In StyleCop Classic, this rule reported a variable or field name which did not begin with a lower-case letter. These
cases are reported by [SA1306](SA1306.md) for fields and [SA1312](SA1312.md) for variables.

## How to fix violations

There are no violations of this rule to fix.

## How to suppress violations

```csharp
[SuppressMessage("StyleCop.CSharp.NamingRules", "SA1301:ElementMustBeginWithLowerCaseLetter", Justification = "Reviewed.")]
```

```csharp
#pragma warning disable SA1301 // ElementMustBeginWithLowerCaseLetter
#pragma warning restore SA1301 // ElementMustBeginWithLowerCaseLetter
```
