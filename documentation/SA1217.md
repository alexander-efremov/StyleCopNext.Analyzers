:memo: This rule is new for StyleCop Analyzers, and was not present in StyleCop Classic.

## Cause

The `using static` directives within a C# code file are not sorted alphabetically by full type name.

## Rule description

A violation of this rule occurs when the `using static` directives are not sorted alphabetically by full type name. Sorting the `using static` directives alphabetically makes the code cleaner and easier to read.

By default, `using static` directives for types in the System namespace precede all other `using static` directives, the same way SA1210 orders System namespaces first. For example, `using static System.Math;` should be placed before `using static Absolutes.Constants;`. To sort all `using static` directives together alphabetically instead, set `systemUsingDirectivesFirst` to `false` (see [Configuration.md](Configuration.md#using-directives)).

Global using directives (C# 10) are analyzed independently from local using directives. Diagnostics and fixes compare only directives which both use, or both omit, the `global` modifier.

## Configuration

This rule is affected by the following settings in **stylecop.json**. See [Configuration.md](Configuration.md) for details. Settings that have an
**.editorconfig** key can also be set there; see [Settings in .editorconfig](Configuration.md#settings-in-editorconfig).

| Setting | Default | Effect on this rule | .editorconfig key |
| --- | --- | --- | --- |
| [`orderingRules.systemUsingDirectivesFirst`](Configuration.md#using-directives) | `true` | When `true`, `System` using directives are expected before the other directives and are not compared with them; when `false`, they are treated like any other directive. | `dotnet_sort_system_directives_first` |

## How to fix violations

To fix an instance of this violation, order the `using static` directives alphabetically by full type name.

## How to suppress violations

```csharp
#pragma warning disable SA1217 // Using static directives should be ordered alphabetically
using static System.Math;
#pragma warning restore SA1217 // Using static directives should be ordered alphabetically
```
